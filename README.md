## What I'm building

**[AI Lead Intelligence System](https://github.com/lukmanabdulhaq/ai-lead-intelligence-system)** — [Live Demo](https://ai-lead-intelligence-system.vercel.app)

Captures leads from WhatsApp, web forms, Telegram and email. Uses Groq/Llama AI to score them HIGH / MEDIUM / LOW, extracts budget, location and intent, then fires an instant Telegram notification — all in under 3 seconds.
